# RaceHub Mobile

Jornada de corrida com descoberta de eventos, favoritos, inscrição e acompanhamento de entrega do kit. React Native/Expo no cliente e ASP.NET Core .NET 10 com EF Core/PostgreSQL na API.

Execute com `docker compose up --build`; no cliente, use `cd mobile`, `npm ci` e `npm start`.

> Demonstração independente com dados fictícios, sem afiliação oficial com os eventos ou sites usados como referência pública.
